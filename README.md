# Amul Stocks Checker

1. Create a GitHub repository and upload these files.
2. In GitHub Settings -> Secrets and variables -> Actions, add:
- BOT_TOKEN
- CHAT_ID
- PINCODE
3. Enable GitHub Actions.
4. Run the workflow once manually.

Note: This starter project uses a simple page-content heuristic. If Amul changes their website or uses JavaScript/API-based stock checks, the detection logic in app.py will need to be updated.
